# 机械葫芦娃 MK-III · Quantum-Exo

一个在浏览器里实时生成和拆解的科幻机甲模型。外甲、镂空观察窗、机构、分层和纹理都由代码生成，不需要 Blender、外部 3D 模型文件或预制贴图。这是数字模型与交互演示，不是实物工程设计。

## 如何运行

本仓库的入口是 `index.html`。发布到静态站点后，直接打开站点即可。要在本地运行，在项目目录启动静态服务器：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

打开 [http://127.0.0.1:8000/](http://127.0.0.1:8000/)。不建议双击用 `file://` 打开。浏览器需支持 WebGL 2，并能访问 jsDelivr。没有安装或编译步骤；Three.js 固定为 **0.169.0**，界面用 Tailwind CSS **3.4.17** 预编译，样式已内嵌，不加载线上 Tailwind 脚本。

## 操作

- **观察视角**：鼠标拖动环绕，滚轮拉近/拉远；也可通过右侧控制台选择正侧、胸部、头冠或背面。
- **四层拆解**：用预设按钮或滑块控制 0–100% 拆解；可以隐藏或独显单层，再选择全部显示。
- **齿轮和活塞**：暂停、设为 0.2×、1× 或 2×，或按 **+5° 单次步进** 暂停并转动主轮 5°。这并不是移动一整齿。
- **显示模式**：PBR 实景、X-Ray 透视和 CAD 风格线框，均使用同一套模型。
- **构图提示**：边距由当前可见模型的包围盒八顶点投影计算，并为可见的控制台留位。视角、缩放、动画与屏幕尺寸都会改变读数。可使用“一键适配”，或手动调整。

## 说明

这是按齿数和相位公式驱动的程序动画；不代表精确物理仿真、零干涉、承载强度或可制造性验证。齿形由程序近似构造，局部接触可能出现微量交叠。视口提示只说明此时此角度下的计算结果，不承诺任意手动镜头都能完整取景。

手机和低配置设备上渲染可能较慢。若初次加载失败，请核对浏览器的 WebGL 2 支持及网络，或尝试近期版本的浏览器。
